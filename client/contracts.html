自己验 / Verify it yourself

任选一个地址，用任意一台能连主网的节点执行：

wasmd query wasm contract <地址> --node http://127.0.0.1:26657 --output json
wasmd query wasm list-contract-by-code <code_id> --node http://127.0.0.1:26657
wasmd query wasm contract-state all <地址> --node http://127.0.0.1:26657 --output json

第三条能把合约的全部状态倒出来，比如金库持币量、锁仓计划、挖矿池余额——不需要相信本页任何一句话。
